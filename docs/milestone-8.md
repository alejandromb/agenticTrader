# Milestone 8 Product Contract

## Outcome

Reduce dashboard cognitive load while preserving evidence, limitations, and
access to existing workflows.

## Guiding principle

Agentic Trading does not display data merely because it is available. Every
chart or panel must help answer an investment question faster or more reliably
than concise text. If it does not improve decision quality, it is not added.

## Intended changes

- Establish research and human review as the default path.
- Reveal quantitative, monitoring, alert, and review tools progressively.
- Clarify the next available human action on each screen.
- Reduce simultaneous controls, repeated metadata, and competing emphasis.
- Preserve direct access for experienced operators.

## Evaluation

Use representative tasks—start research, identify limitations, inspect evidence,
record disposition, and revisit a monitored thesis. Compare navigation steps,
visible competing actions, completion errors, and operator comprehension against
the Milestone 7 dashboard.

## Not in this milestone

No new analytics, charts, model capabilities, automation, or execution paths.
The future-dashboard list remains a measured backlog.
